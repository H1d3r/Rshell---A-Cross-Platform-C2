# Rshell - 跨平台主机资产管理平台

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

Rshell 是一款开源的 Golang 编写的跨平台主机资产管理平台，面向企业内网运维场景，解决多主机统一管理、配置核查与批量任务执行的效率问题。

## 核心特性

- **跨平台支持**：Agent 支持 Windows、Linux、Darwin 等系统
- **多协议通信**：支持 Websocket、TCP、KCP、HTTP 等多种通信方式，适应复杂网络环境下的管理需求
- **主机资产管理**：统一纳管服务器，资产信息可视化展示，支持笔记与颜色标记
- **批量任务执行**：脚本批量下发、命令执行、交互式终端、文件管理
- **配置核查**：批量采集主机配置信息，辅助基线核查与合规检查
- **Web 可视化**：Vue.js 前端，提供友好的集中管理界面

## 快速开始

下载对应平台的二进制文件并运行：

```bash
./Rshell -p 8089
```

默认账号 admin，密码首次运行后随机生成。
